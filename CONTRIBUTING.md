## Branching & Pull Requests

- Target the `dev` branch for all pull requests (`main` is reserved for reviewed releases).
- Ensure formatting (`cargo fmt --check`), lints (`cargo clippy --workspace --all-targets -- -D warnings`), docs (`RUSTDOCFLAGS="-D warnings" cargo doc --no-deps --workspace`), and tests (`cargo test --workspace`) pass before opening a PR.
